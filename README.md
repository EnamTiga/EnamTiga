## 🚀 Featured Project

### [gasopname](https://github.com/EnamTiga/gasopname)

A weekly stock-taking (*opname*) worksheet web app for construction site engineers — a purpose-built replacement for a sprawling Google Sheets workbook.

<details>
<summary><b>⚙️ What it does</b></summary>
<br>

- **Projects** — construction packages with engineer, company, start date, and status
- **Mandors & SPKs** — contractors and their work orders, each with budget breakdowns (RAB)
- **Weekly opname** — record realized volume per line item per week; value = volume × unit price
- **Kasbon** — cash advances with deductions taken from payments
- **Pengajuan** — weekly payment submissions (`draft → diajukan → dibayar`); submitting freezes a snapshot and locks the week
- **Dashboard** — project overview with key figures

</details>

**Stack:** React 19 · TypeScript · Hono · Cloudflare Workers · Cloudflare D1 · Tailwind CSS v4 · Vitest
